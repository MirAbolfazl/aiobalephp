# aiobale-php

Async PHP client for the Bale messaging API using AMPHP.

This project includes models, enums, API method classes, WebSocket connectivity, gRPC-Web requests, Protobuf encoding/decoding, file sending, and event routing.

> This library is not an official Bale tool. Use it only with your own account and in compliance with Bale API rules and limitations.

- PHP 8.2+
- Composer

```bash
cd /path/to/aiobalephp
composer install
```

## Quick start

```php
<?php

require __DIR__ . '/vendor/autoload.php';

use Aiobale\Client\Client;
use function Amp\async;

$client = new Client(sessionFile: __DIR__ . '/var/bale-session.json');

async(function () use ($client): void {
    $challenge = $client->startPhoneAuth(
        phoneNumber: '+989123456789',
        appId: 4,
    )->await();

    $code = readline('Verification code: ');
    $auth = $client->validateCode(trim($code), $challenge->transaction_hash)->await();

    echo 'Logged in: ' . $auth->user->name . PHP_EOL;
    $client->connect()->await();
})->await();
```

## Authentication flows

- `startPhoneAuth()` begins the phone-based sign-in flow.
- `validateCode()` submits the code received by SMS or voice call.
- `validatePassword()` completes the two-factor password step.
- `signUp()` creates a new account when the service requires registration.

## WebSocket and requests

```php
$client->connect()->await();
$client->invoke($method)->await();
```

## Swagger / OpenAPI docs

This repository ships with generated Swagger/OpenAPI documentation in both English and Persian.

Generate the docs:

```bash
composer docs:swagger
```

Serve the docs locally:

```bash
composer docs:swagger:serve
```

Then open:

```text
http://127.0.0.1:8080/
```

Swagger source files are generated by `docs/swagger/generate.php` and include:

- `docs/swagger/openapi.en.yaml`
- `docs/swagger/openapi.fa.yaml`
- `docs/swagger/index.html`
- `docs/swagger/generate.php`
